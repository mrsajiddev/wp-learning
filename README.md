## Project Overview
This repository contains the custom WordPress development work for the project. It includes custom themes, plugins, and WordPress configurations required for the website.
## Project Structure
wp-content/
├── themes/
│   └── child-theme/
├── plugins/
└── uploads/

## Technologies Used
- WordPress
- PHP
- HTML5
- CSS3
- JavaScript
- MySQL

## Installation
1. Clone the repository.
2. Copy the wp-content folder into your WordPress installation.
3. Import the project database.
4. Update the wp-config.php file with your database credentials.
5. Start your local server.
6. Log in to WordPress.

## Features
- Custom WordPress Theme
- Custom Plugin Development
- Responsive Design
- Elementor Compatible
- WooCommerce Support
